Chapter 6 Other ComDim methods

In the previous sections, we have only used ComDim-PCA, but many other ComDim versions exist. ComDim can be regarded as a chemometric method able to compact the relevant information of the data into a reduced subspace, defined by the scores, the loadings and the saliences. Although most ComDim analyses employ Principal Component Analysis (PCA) as the core method to find this reduced space, other approaches can be used.

The R.ComDim package includes a few of those other methods, as well as some additional functions to allow the users to create their own ComDim methods.

6.1 ComDim-Partial Least Squares Discriminant Analysis (ComDim-PLSDA)

ComDim-PLSDA is executed with the function ComDim_PLS(), by providing a y vector with the sample class labels and setting method = 'PLS-DA'. The output object contains the typical PLS figures of merit (R2X, R2Y, Q2, DQ2), the VIP (Variable Importance in Projection) scores per variable and per block, the PLS regression coefficients B and B0, and the predicted class assignments along with a confusion matrix, sensitivity and specificity per class.

resultsPLSDA <- ComDim_PLS(allMB,
                              y = c(rep('NI',4), rep('DOX',4), rep('OFF',4)),
                              ndim = 2, method = 'PLS-DA')

6.1.1 Predicting new samples with ComDim-PLSDA

The function PredictMultiBlock() projects a new MultiBlock dataset into an existing ComDim model. It computes global and local scores for the new samples, predicts the Y-block (class assignments for PLSDA), and — when the true labels y are supplied — also returns Q2, DQ2, sensitivity, specificity and a confusion matrix for the new samples.

# Split the dataset into a training set (9 samples, 3 per class)
# and a test set (3 samples, 1 per class).
allMB_train <- FilterSamplesMultiBlock(allMB, sampleNames(allMB)[c(1:3, 5:7, 9:11)])
allMB_test  <- FilterSamplesMultiBlock(allMB, sampleNames(allMB)[c(4, 8, 12)])

y_train <- c(rep('NI', 3), rep('DOX', 3), rep('OFF', 3))

# Fit the model on the training set
modelPLSDA <- ComDim_PLS(allMB_train, y = y_train,
                             ndim = 2, method = 'PLS-DA')

# Project the 3 test samples; supply true labels to get Q2/DQ2 and statistics
y_test <- c('NI', 'DOX', 'OFF')
predPLSDA <- PredictMultiBlock(allMB_test, y = y_test, model = modelPLSDA)

predPLSDA@Prediction$Y.pred          # Raw predicted Y scores --> Need to have class names and sample names.
predPLSDA@Prediction$predClass        # Predicted class assignments
predPLSDA@Prediction$confusionMatrix  # Confusion matrix for test set
predPLSDA@Q2                          # Q2 for test samples per class
predPLSDA@DQ2                         # DQ2 for test samples per class

# Plot training and test samples on the model score space
trainQ <- as.data.frame(modelPLSDA@Q.scores) %>%
  mutate(sample.id   = rownames(modelPLSDA@Q.scores),
         sample.type = case_when(grepl('DOX', sample.id) ~ 'DOX',
                                 grepl('NI',  sample.id) ~ 'NI',
                                 grepl('OFF', sample.id) ~ 'OFF'),
         set = 'Train')

testQ <- as.data.frame(predPLSDA@Q.scores) %>%
  mutate(sample.id   = rownames(predPLSDA@Q.scores),
         sample.type = y_test,
         set = 'Test')

allQ_PLSDA <- bind_rows(trainQ, testQ)

ggplot(allQ_PLSDA, aes(x = CC1, y = CC2, color = sample.type, shape = set)) +
  geom_point(size = 3) +
  theme_minimal() +
  labs(title = 'PLSDA: Training and test scores', x = 'CC1', y = 'CC2')

6.2 ComDim-Partial Least Squares Regression (ComDim-PLSR)

ComDim-PLS can be executed with the same function ComDim_PLS(), by providing a y regression vector (i.e. numerical) and setting method = 'PLS-R'. The output contains the typical PLS figures of merit (R2X, R2Y, Q2), the VIP scores, the PLS regression coefficients B and B0, and the predicted y values.

# Training: 9 samples (3 per class); test: 3 samples (one per class, held out).
# The training and test sets are non-overlapping.
allMB_train <- FilterSamplesMultiBlock(allMB, sampleNames(allMB)[setdiff(1:12,c(2,6,10))])
allMB_test  <- FilterSamplesMultiBlock(allMB, sampleNames(allMB)[c(2, 6, 10)])

# Numerical response: 1 = NI, 2 = DOX, 3 = OFF
y_train <- rep(1:3, each = 3)

# Fit ComDim-PLS-R with 2 components
resultsPLSR <- ComDim_PLS(allMB_train,
                              y = y_train,
                              ndim = 2, method = 'PLS-R')

# Figures of merit
resultsPLSR@R2X
resultsPLSR@R2Y   # Cumulative R2Y per CC (CC1, CC2)
resultsPLSR@Q2    # Cross-validated Q2

# Regression coefficients and training-set predictions
head(resultsPLSR@PLS.model$B)       # B has variable names as rownames
resultsPLSR@Prediction$Y.pred       # Training predictions (sample names in rownames)

# Project the test set
y_test <- c(1, 2, 3)  # True y values for the 3 test samples
predPLSR <- PredictMultiBlock(allMB_test, y = y_test, model = resultsPLSR)

predPLSR@Prediction$Y.pred  # Predicted y for the 3 test samples
predPLSR@Q2                 # Q2 for the test set

# Plot predicted vs actual Y for training and test sets
pred_df <- rbind(
  data.frame(actual    = y_train,
             predicted = as.vector(resultsPLSR@Prediction$Y.pred),
             set       = 'Train'),
  data.frame(actual    = y_test,
             predicted = as.vector(predPLSR@Prediction$Y.pred),
             set       = 'Test')
)

ggplot(pred_df, aes(x = actual, y = predicted, color = set)) +
  geom_point(size = 3) +
  geom_abline(intercept = 0, slope = 1, linetype = 'dashed') +
  theme_minimal() +
  labs(title = 'PLSR: Predicted vs Actual', x = 'Actual Y', y = 'Predicted Y')

6.3 ComDim-Orthogonal PLS (ComDim-OPLS)

ComDim-OPLS is executed with the function ComDim_OPLS(). It extends the PLS formulation by extracting orthogonal components — systematic variation in X that is uncorrelated with Y — before computing the predictive component(s). This produces a cleaner separation between structured noise and the Y-relevant signal, and is especially useful when many orthogonal sources of variation exist in the data (e.g. batch effects, biological confounders).

The function supports both discriminant analysis (method = 'OPLS-DA') and regression (method = 'OPLS-R'). The number of predictive components is controlled by ndim (default 1) and the number of orthogonal components by nort (default 1).

The output object is a ComDim object that contains, in addition to the usual predictive slots:

  • @Orthogonal — a list with the orthogonal scores (Q.scores, T.scores), orthogonal loadings (P.loadings.ort), and orthogonal saliences (Saliences.ort).
  • @VIP / @VIP.block — VIP scores with three columns per block: p (predictive VIP), o (orthogonal VIP), and tot (combined total VIP, used in @VIP).
  • @R2X, @R2Y, @Q2, @DQ2 (OPLS-DA only) — the usual figures of merit.
# ComDim-OPLS-DA: 1 predictive component, 1 orthogonal component
resultsOPLSDA <- ComDim_OPLS(allMB,
                                 y = c(rep('NI', 4), rep('DOX', 4), rep('OFF', 4)),
                                 ndim = 1, nort = 1,
                                 method = 'OPLS-DA')

6.4 Computation strategies: CompMethod and Partitions

All ComDim functions accept a CompMethod argument that controls the internal algorithm used to compute the common dimensions. For most datasets the default ('Normal') is fine, but the alternatives can give large speed gains when the data geometry is extreme (many more variables than samples, or a very large number of samples).

CompMethod Description
'Normal' Exact SVD on the full concatenated block (default)
'Kernel' Works on the n × n kernel matrix instead of the p × n data matrix.
'PCT' PCA pre-compression before the ComDim step, recommended for large blocks with redundant variables
'Wide' Column-partitioned computation, recommended for very wide blocks
'Tall' Row-partitioned computation, recommended for blocks with many samples and with n >> p

The Partitions argument is an integer divisor used with 'Tall' and 'Wide' to control how the data are split. It can also be used with 'Kernel' and 'PCT' to limit memory use during pre-compression.

# Synthetic dataset: 500 samples, 2 x 1 000 variables, 4 latent sources,
# 5 % noise.  seed = 42 ensures the example is fully reproducible.
allMB <- SimulateMultiBlock(n = 500, p = 2000, n_sources = 4,
                            noise = 0.05, n_blocks = 2, seed = 42)
allMB <- NAInfRemoveMultiBlock(allMB, na.method = 'none', minfrac = 0.2)
allMB <- NormalizeMultiBlock(allMB, method = 'norm')

# Default: exact SVD — accurate for any dataset size
t_normal <- system.time(
  results_normal <- ComDim_PCA(allMB, ndim = 4, CompMethod = 'Normal')
)

# Kernel: build an n×n cross-product matrix — requires n < p per block
# (here n = 500, p = 1 000 per block, so the condition is satisfied)
t_kernel <- system.time(
  results_kernel <- ComDim_PCA(allMB, ndim = 4, CompMethod = 'Kernel')
)

# PCT: compress each block with PCA first, then run ComDim on the scores
t_pct <- system.time(
  results_pct    <- ComDim_PCA(allMB, ndim = 4, CompMethod = 'PCT')
)

# Wide: partition the blocks column-wise; Partitions controls how many pieces
t_wide <- system.time(
  results_wide   <- ComDim_PCA(allMB, ndim = 4,
                               CompMethod = 'Wide', Partitions = 3)
)

# Tall: partition row-wise — only suitable when blocks are narrow (< 1 000 vars)
t_tall <- system.time(
  results_tall   <- ComDim_PCA(allMB, ndim = 4,
                               CompMethod = 'Tall', Partitions = 3)
)

# Elapsed time per method
timing_df <- data.frame(
  Method  = c('Normal', 'Kernel', 'PCT', 'Wide', 'Tall'),
  Seconds = c(t_normal['elapsed'], t_kernel['elapsed'],
              t_pct['elapsed'],    t_wide['elapsed'],
              t_tall['elapsed'])
)
print(timing_df)

ggplot(timing_df, aes(x = reorder(Method, Seconds), y = Seconds, fill = Method)) +
  geom_bar(stat = 'identity') +
  coord_flip() +

6.5 Other extensions

The ComDim_Exploratory() and ComDim_y() functions enable highly customized Com-Dim implementations for exploratory and regression/discriminant analysis. By utilizing the FUN parameter, you can integrate any chemometric method that performs bilinear decompositions into the Com-Dim core. This flexible approach generates method-specific scores alongside loadings and saliences, allowing you to simultaneously evaluate individual variable impacts and overall block contributions.

6.5.1 Example of ComDim-ICA

The function used to execute Independent Component Analysis (ICA) was ica() from the ica package. In order for the ComDim_Exploratory() function to understand the output of ica(), we embedded it into another function that returns the source estimates (representative of the samples information, analogous to the PCA scores) named fun.ICA.

library(ica)

fun.ICA <- function(W, ndim,...){
  # W is the concatenated MB.
  # ndim is the number of components.
  # X and nc are the arguments of ica::ica.
  result <- ica::ica(W, ndim)
  sources <- result$S
  # The function must return the source estimates
  # The analogue to the PCA scores for ICA.
  return(sources)
}

6.5.2 Example of ComDim-PLS (version ropls)

The function used to execute PLS here was opls(), obtained from the ropls package. In this case, fun.PLS is used to capture the output from the PLS analysis (scores,P,W,U,Q,y). type=regression is set to calculate R2Y, Q2,… as with ComDim_Pls_MB().

library(ropls) # From bioconductor
fun.PLS <- function(W, y, ndim,...){
  # W is the concatenated MB.
  # ndim is the number of components.
  # X and nc are the arguments of ica::ica.
  output <- list()
  result <- ropls::opls(x = W, y = y, predI = ndim,
                        fig.pdfC = 'none',
                        info.txtC = 'none')
  # The returning object must be a list containing the following 6 elements:
  output$scores <- result@scoreMN[,1]
  output$P <- result@loadingMN[,1]
  output$W <- result@weightMN[,1]
  output$U <- result@uMN[,1]
  output$Q <- result@cMN[,1]
  output$y <- result@suppLs$yModelMN
  return(output)
}

                          ndim = 2,
                          type = 'regression',

                          method = 'PLS(ropls)')

6.5.4 Example of ComDim-OPLSDA (version ropls)

To implement O-PLS as the core of Com-Dim, we follow the same procedure used for ComDim-PLS-DA, but this time the function passed through the FUN parameter returns in addition the orthogonal scores (orthoscores).

# Apply ComDim-OPLSDA on a 2-class subset (NI vs OFF).
allMB_small <- FilterSamplesMultiBlock(allMB_ica,
                                       sampleNames(allMB_ica)[c(1:4, 9:12)])

# OPLS-DA wrapper around ropls::opls.
fun.OPLSDA <- function(W, y, ndim, ...) {
  # ropls requires a -1/+1 vector for binary DA (not a dummy matrix).
  Y <- c(-1, 1)[apply(y, 1, function(x) match(1, x))]

  # Ort phase: ropls finds 1 predictive + 1 orthogonal component.
  result <- ropls::opls(x = W, y = Y, predI = 1, orthoI = 1,
                fig.pdfC = "none", info.txtC = "none")

  # Expand ropls's 1-element Y-loading to the 2-column dummy-matrix format.
  # class 1 (encoded -1) gets -cMN, class 2 (encoded +1) gets +cMN.
  Q_expanded <- c(-result@cMN[, 1], result@cMN[, 1])

  # Orthoscores
  ort_scores <- result@orthoScoreMN 

  list(
    scores      = result@scoreMN[, 1],
    P           = result@loadingMN[, 1],
    W           = result@weightMN[, 1],
    U           = result@uMN[, 1],
    Q           = Q_expanded,
    y           = result@suppLs$yModelMN,
    orthoscores = ort_scores
  )
}

resultsOPLSDA_ropls <- ComDim_y(allMB_small,
                                y = c(rep("NI", 4), rep("OFF", 4)),
                                ndim = 1,
                                nort = 1,
                                type = "discriminant",
                                FUN = fun.OPLSDA,
                                method = "OPLSDA(ropls)",
                                cv.k = 0)
